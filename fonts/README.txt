Bundled fonts shared by every video (rendering needs no network access or system fonts).

  jetbrains-mono-latin-500     JetBrains Mono     SIL Open Font License 1.1   (LICENSE-JetBrains-Mono.txt)
  STIXGeneral*.ttf             STIXGeneral        STIX Fonts license          (LICENSE-STIXGeneral.txt)
  DejaVuSansMono.ttf           DejaVu Sans Mono   DejaVu Fonts license        (LICENSE-DejaVu.txt)
Pagella is used by the matplotlib videos (midpoint-rule, leapfrog, euler, rk4); the rest by ieee754.
The woff2 files are the Latin subsets published by the @fontsource npm packages.
